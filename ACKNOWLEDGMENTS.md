# Acknowledgments

This experimental port builds on the public [vLLM-Neuron](https://github.com/vllm-project/vllm-neuron) plugin and the Qwen model family.

The initial model-integration approach was informed by public Trainium examples from [Armin Agha-Ebrahim's Armin-Neuron repository](https://github.com/arminagha1234/Armin-Neuron), including its Qwen and Gemma serving work. Thank you to Armin for publishing those references.

This repository is an independent experimental project and is not an official AWS, vLLM, Qwen, Alibaba or Armin-Neuron release.
